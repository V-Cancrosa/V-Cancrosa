# Zasługi i licencje

Kilka efektów na stronie to adaptacje penów z CodePen (z kolekcji [CodePenFolders](https://github.com/V-Cancrosa/CodePenFolders)).
Kod został przepisany i dopasowany do stylu postaci, ale pomysły i techniki należą do autorów poniżej.

| Pen | Autor | Gdzie na stronie |
|---|---|---|
| [Fallout 3 Terminal](https://codepen.io/32bitkid/pen/DrXOVg) | J Holmes | terminal Fallout: Equestria na stronie głównej — pas skanowania, odblaski szkła, poświata, pisanie z nierównym rytmem |
| [Fallout Terminal Inspired CSS Theme](https://codepen.io/macktropolis/pen/vNMRpK) | Mack Richardson | ten sam terminal — migotanie ekranu i link w nawiasach [ ] |
| [Neon Glass Context Menu](https://codepen.io/simeydotme/pen/PwwYZOe) | Simey | Ragnar — neonowe krawędzie telefonu o 2:14 |
| [Modal Animations](https://codepen.io/designcouch/pen/obvKxm) | Jesse Couch | otwieranie podglądu obrazków; u Vince'a rozkładanie się jak plan |
| [[PURE CSS] border animation without svg](https://codepen.io/Rplus/pen/abPLGx) | Rplus | Vince — złota linia obiegająca karty wypraw |
| [Animated Back Glow](https://codepen.io/georgehastings/pen/xgwxgo) | George Hastings | strona główna — poświata pod sceną wyboru postaci |
| [Three Dots — CSS loading animations](https://codepen.io/nzbin/pen/GGrXbp) | Zongbin | Myr — kropki przetwarzania w terminalu |
