# Vince Cancrosa

Strona Vincenta „Vince” Cancrosy — wilka grzywiastego i głównej fursony.

Statyczna strona (jeden `index.html`, bez zależności z zewnątrz), hostowana na GitHub Pages.

- `index.html` — cała strona; miejsca do uzupełnienia są oznaczone `[...]`
- `img/` — portret (`img/vince.webp`) i arty
- `fonts/` — VT323 i IBM Plex Mono (SIL Open Font License, pliki licencji obok)

Własna domena: plik `CNAME` z nazwą domeny + rekordy DNS według
https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site
