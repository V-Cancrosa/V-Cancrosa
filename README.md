# The One Above Them

Strona z postaciami (fursonami) i projektami. Statyczna, bez zależności z zewnątrz, hostowana na GitHub Pages.

- `index.html` — strona główna: postacie, projekty (muzyka, TTRPG, przyszłe streamy), kontakt
- `vince.html`, `chip.html`, `ragnar.html`, `toro.html` — karty postaci z Cancrosa Files
- `myr.html`, `zarin.html` — karty postaci z Cancrosa Verse (głęboki kosmos, kanon roboczy)
- `styles.css` — wygląd strony głównej i starszych podstron
- `vince.css` + `vince.html` — strona Vince'a we własnym stylu (kolejne postacie dostaną swoje)
- `char.js` — wspólny skrypt stron postaci: przełącznik PL/EN, podgląd obrazków, animacje przy przewijaniu
- `img/` — portrety i arty (zawsze z podpisem autora)
- `fonts/` — Archivo, Inter, Space Mono (SIL Open Font License, pliki licencji obok)

Miejsca do uzupełnienia są oznaczone ✎ albo komentarzem w kodzie.
Nowa postać: skopiuj `vince.html` jako np. `toro.html` i podmień treść.

Własna domena: plik `CNAME` z nazwą domeny + rekordy DNS według
https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site
